# Data

The dataset used in this analysis (`owid-covid-data.csv`, about 95 MB) is not stored in this repo because of its size.

Download it from Our World in Data's GitHub repo:
https://github.com/owid/covid-19-data/blob/master/public/data/owid-covid-data.csv

Place the downloaded file in this folder, so the path is `data/owid-covid-data.csv`. Then knit `project_final_report.Rmd` from the repository root.

The report was produced with the final version of the dataset, which covers 2020-01-01 to 2024-08-14. The file has not received new data since August 2024, so downloading it now should reproduce the same numbers.
